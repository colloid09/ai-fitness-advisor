![Status](https://img.shields.io/badge/Status-Completed-success)

An **AI-powered fitness recommendation web application** that generates **personalized workout plans** based on user inputs such as age, gender, height, weight, fitness goals, and injury history.

This project showcases the practical application of **Artificial Intelligence**, **Full Stack Development**, and **REST APIs** in the health & fitness domain.

---

## 🚀 Features

- 👤 User Authentication (Register / Login / Forgot Password)
- 📋 Fitness Details Form
- 🤖 AI-Generated Personalized Fitness Plan
- 🏃 Exercise Recommendations
- 📄 Download Fitness Plan as PDF
- 📱 Fully Responsive UI
- 🔐 Secure Backend APIs

---

## 🛠️ Tech Stack

### Frontend
- React.js  
- Tailwind CSS  
- React Router  

### Backend
- FastAPI / Node.js  
- RESTful APIs  

### AI / ML
- Large Language Model (LLM)
- Prompt-based Recommendation System

### Database
- MongoDB 

---

## 📊 System Architecture & Workflow

1. User registers and logs in  
2. User fills fitness details (age, height, weight, goal, injury, etc.)  
3. Data is sent to the backend server  
4. AI model processes the inputs  
5. Personalized fitness plan is generated  
6. Results are displayed on the UI  
7. User can download the plan as a PDF  

---

## 🧠 Problem Statement

Traditional fitness systems provide **generic workout plans** that do not adapt to individual users.

### Limitations of Existing Systems:
- Same plan for everyone  
- No injury consideration  
- No intelligent personalization  

### Proposed Solution:
This system uses **AI-based reasoning** to generate:
- Customized fitness plans  
- Goal-oriented workouts  
- Injury-aware recommendations
